# logic/地区相关 — 地区权限检查

> 从 `utils/地区/守卫.ts` 下沉而来，解决 utils→logic 层倒置。

## 迁移原因

原 `utils/地区/守卫.ts` 中的权限检查函数依赖 `logic/联军相关/设置权限`，
违反了 `utils ← logic` 的依赖方向（utils 不应依赖 logic）。

## 导出清单

| 函数 | 用途 |
|------|------|
| `地区查询权限检查` | 查看地区军事/核反应堆等情报的权限检查 |
| `地区驻扎权限设置检查` | 设置地区驻扎权限 |
| `地区机场权限设置检查` | 设置地区机场权限 |
| `地区总督设置检查` | 设置地区总督 |
| `地区司令设置检查` | 设置地区司令 |
| `部署列车炮权限检查` | 部署列车炮 |
| `列车炮炮击权限检查` | 列车炮炮击 |

## 类型导出

| 类型 | 说明 |
|------|------|
| `地区权限检查动作` | 权限动作联合类型 |
| `地区权限检查结果` | 检查结果（含地区解析 + 权限信息） |
| `地区查询权限结果` | 查询权限结果别名 |

## 依赖关系

```
logic/地区相关/权限检查
  ├── logic/联军相关/设置权限  ← 玩家联军权限设置()
  └── utils/                   ← 玩家检查()、玩家联军检查()、地区解析()
```

## 仍留在 utils/地区/守卫.ts 的函数

- `驻扎检查()` — 不依赖 logic，纯数据守卫
- `机场使用权限检查()` — 不依赖 logic，纯数据守卫
