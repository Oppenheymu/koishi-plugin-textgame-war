# infrastructure — 基础设施层

> 纯工具函数，零业务依赖。可被任何层安全引用。

## 目录结构

```
infrastructure/
├── index.ts          ← barrel 导出
├── random/           ← 随机数
│   └── index.ts        TRandom() — 三角分布随机
├── sqids/            ← ID 生成
│   └── index.ts        获取注册Sqids()、获取联军Sqids()
├── 插件加载/         ← 插件加载
│   └── index.ts        批量加载插件()
├── 游戏记录/         ← 服务记录
│   └── index.ts        确保服务记录()
├── 版本日志/         ← 版本日志
│   └── index.ts        获取版本日志()、格式化版本日志()、列出所有版本() 等
└── 游戏资源/         ← 游戏资源
    ├── index.ts        生成随机图片片段()
    ├── 目录查找.ts      资源目录定位
    └── 随机图片.ts      随机图片生成
```

## 设计原则

1. **无业务逻辑**：不依赖 `types` 以外的任何业务模块
2. **无副作用**：除 `确保服务记录()` 和 `批量加载插件()` 外，均为纯函数
3. **全局可用**：任何层都可以 `import { ... } from '@/infrastructure'`
