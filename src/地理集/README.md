# 地理集 — 地理空间领域

> 坐标、距离、空间索引、相邻查询、旅行计算。
> 依赖 `infrastructure`，不依赖 `utils`/`logic`。

## 目录结构

```
地理集/
├── index.ts          ← barrel 导出
├── 坐标解析.ts        地区编号转经纬度()、经纬度转地区编号()
├── 距离计算.ts        计算真实距离()、格式化距离()
├── 空间索引.ts        确保空间索引就绪()、空间索引查询()
├── 相邻查询.ts        获取相邻地区编号()
└── 旅行计算.ts        计算旅行时间()、旅行路径规划()
```

## 核心概念

- **地区编号** = 经纬度编码（如 `A001` → `(30.5, 120.3)`）
- **空间索引** = 基于 R-tree 的地理查询加速
- **旅行计算** = 考虑地形、铁路的路径规划

## 导入方式

```typescript
import { 地区编号转经纬度, 格式化距离 } from '@/地理集';
```
