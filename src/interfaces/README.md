# interfaces — 接口适配层

> 用户对话与插件之间的翻译官。把聊天消息翻译成对领域层的调用，再把结果翻译成人类可读的文案。

## 这个分层负责什么

- **指令注册**：`ctx.command("xxx").action(...)` 的声明、别名、参数定义
- **参数解析**：从 session 中取出指令参数、@目标、引用消息等
- **回复文案**：把领域层返回的结果拼装成给玩家看的文本（含格式化）
- **错误转译**：捕获领域层抛出的 Error，把 message 作为回复返回给用户

## 这个分层不负责什么

- 业务规则与数据访问 → [contexts/](../../contexts/)（本层只调用，不实现）
- 跨上下文共享的会话守卫 → [shared/session](../../shared/)
- 装配（哪些指令最终被加载）→ [composition/](../../composition/)

## 目录结构

```
interfaces/
├── commands/               # 玩家指令集
│   ├── common/             # 跨域基础指令：版本日志、地图查看、改名、跨端绑定
│   │   └── target/         # 目标解析（@玩家 / UID → 玩家资料）
│   ├── coalition/          # 联军指令：生命周期 / 查询 / 权限 / 分配
│   ├── military/           # 军事指令：补给 / 军衔 / 查询 / 生产
│   ├── player/             # 玩家指令：注册 / 查询 / 工人 / 科技 / 资源 / 地堡 / 生产
│   ├── region/             # 地区指令：查询 / 建筑 / 权限 / 战斗 / 战略 / 仓储 / 资源
│   └── war/                # 战争指令（未接线，登记于 .fallowrc.json dynamicallyLoaded）
└── admin/                  # 管理员指令集
    ├── 稽查/               # 查看玩家资料 / 联军名称 / 名称审核
    └── 预设/               # 初始化地区表 / 服务表 / 地区洗牌
```

## 指令的标准写法

```ts
export function 分配装备(ctx: Context) {
    ctx.command("分配装备 <编号:number> <装备:string> <数量:number>").action(
        async ({ session }, 编号, 装备, 数量) => {
            try {
                // 1. 守卫检查（会话/玩家/联军/驻扎）
                // 2. 调用领域工作流（import 自 #ctx/<上下文> 根 barrel）
                // 3. 组装回复文案
            } catch (error) {
                return (error as Error).message;   // 4. 错误转译
            }
        },
    );
}
```

然后汇入所在分组的 `index.ts` 指令数组，最终由 [composition/指令集.ts](../../composition/) 装配。

## 依赖规则（fallow 强制）

允许引用：`#/config`、`#/infrastructure`、`#shared/*`、**各上下文根 barrel**（`#ctx/military` 等）。

禁止：
- 深入上下文内部（`#ctx/military/domain/...` ✗）
- 直接操作数据库表（须经上下文的领域服务）
- 引用 composition

## 命名约定（本层特有）

| 对象 | 规则 | 示例 | 反例 |
|---|---|---|---|
| 指令分组目录 | 中文，**不带「相关」后缀** | `查询` `权限` `生命周期` | `查询相关` |
| 指令文件 | 中文 | `分配资料.ts` `邀请加入联军.ts` | |
| 指令注册函数 | `<指令名>指令` 或直接 `<指令名>` | `分配装备` `制取地区资源` | |
| 指令数组导出 | `<分组>指令` | `查询指令` `跨端指令` | `查询相关指令` `个人相关` |
| 组内共享文件 | `共享.ts` | `生命周期/共享.ts` | |
