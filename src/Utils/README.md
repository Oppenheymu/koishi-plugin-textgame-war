# utils — 业务解析层

> 纯数据解析、守卫检查、安全更新的统一入口。
> **禁止依赖 `logic`、`services`、`指令集`、`管理集`。**

## 目录结构

```
utils/
├── index.ts          ← barrel 导出（唯一合法入口）
├── types.ts          ← 跨子模块共享类型
├── 会话/             ← 会话守卫
│   └── index.ts        会话检查()、用户检查()、发送并抛出错误()
├── 玩家/             ← 玩家领域
│   ├── 查询.ts         合并玩家资料()、获取玩家完整资料()
│   ├── 更新.ts         更新玩家资料()（无读直写优化）
│   ├── 守卫.ts         玩家检查()
│   └── 名称.ts         获取玩家展示名称()
├── 联军/             ← 联军领域
│   ├── 查询.ts         联军解析()
│   ├── 守卫.ts         玩家联军检查()
│   ├── 权限.ts         获取联军权限等级()
│   ├── 贡献.ts         获取联军贡献排行数据()、获取成员联军贡献() 等
│   └── 名称.ts         获取联军展示名称()
├── 地区/             ← 地区领域
│   ├── 查询.ts         地区解析()、地区基础解析()、当前地区解析()
│   ├── 更新.ts         更新地区资料()、更新地区战略资料()（无读直写优化）
│   ├── 守卫.ts         驻扎检查()、机场使用权限检查()
│   └── 名称.ts         获取地区展示名称()
└── 目标/             ← 目标解析
    ├── 玩家.ts         目标解析()
    └── 联军.ts         目标联军解析()
```

## 依赖方向

```
会话 ← 玩家 ← 联军 ← 地区
            ↘       ↗
             目标 ──┘
```

- `会话` 无内部依赖
- `玩家` 依赖 `会话`
- `联军` 依赖 `会话`、`玩家`
- `地区` 依赖 `会话`、`玩家`、`联军`
- `目标` 依赖 `玩家`、`联军`

## 查询优化说明

### 无读直写（更新操作）

`更新玩家资料()` 和 `更新地区资料()` 采用**静态字段映射**，根据字段名自动分流到正确的数据库表，无需先读取再写入：

```typescript
// 旧方式：3~4 次 IO（2次读 + 1~2次写）
const 玩家 = await ctx.database.get('马列玩家表', { id });
await ctx.database.set('马列玩家表', { id }, 更新数据);

// 新方式：1~2 次 IO（仅写入）
更新玩家资料(ctx, id, { 私人军队: 100, 战争保护期: true });
// 自动拆分：私人军队 → 马列玩家战争表, 战争保护期 → 马列玩家表
```

### 轻量查询（地区解析）

`地区基础解析()` 只查主表（1 次 IO），适用于不需要子表数据的场景：

```typescript
// 全量查询（5 次 IO）
const 全量 = await 地区解析(ctx, 'A001');

// 轻量查询（1~2 次 IO）
const 轻量 = await 地区基础解析(ctx, 'A001');

// 当前地区 - 轻量模式
const 轻量 = await 当前地区解析(ctx, session, true);
```
