# koishi-plugin-textgame-war

**征战文游** —— Koishi 平台大型多人在线文本策略战争游戏。

玩家在聊天机器人（OneBot / Discord / Telegram）中通过文本指令管理自己的工业帝国：发展生产、攀爬科技、制造军备、建设地区、结成联军、争夺领土。

---

## 安装

```bash
npm install koishi-plugin-textgame-war
```

## 前置依赖

本插件需要以下服务支持：

| 依赖 | 说明 |
|------|------|
| `database` | Koishi 数据库服务，存储所有游戏数据 |
| `cron` | 定时任务服务，驱动签到重置、生产恢复等 |
| `amIAlt`（`koishi-plugin-infra-am-i-alt`） | 身份验证插件，用于跨平台账号关联 |

请确保在 Koishi 配置中启用以上服务。

## 游戏玩法

### 入门流程

1. **注册** — 创建角色，随机获得初始资源（工人 4000-16000、生活资料 8000-90000、石油 50-800、钢铁 100-500）
2. **签到** — 每日签到获取随机补给
3. **生产** — 消耗工人与生产技术产出现金（每小时恢复 1 次生产次数，上限 8 次）
4. **开采资源** — 开采铁矿石、石油、铝土矿；土法炼钢
5. **提升科技** — 投入资源攀爬科技树，解锁高级建造与军备
6. **军事生产** — 制造陆军装备、空军飞机、弹药
7. **驻扎地区** — 驻扎后参与地区建设
8. **地区建设** — 修建基础设施、公路、机场、港口、居民区、仓库（受地形惩罚）
9. **加入联军** — 加入或创建联军，共享领土，协同发展
10. **争夺领土** — 控制地图地区，扩展势力范围

### 核心系统

#### 工业生产

- `生产` — 消耗工人产出金钱（扣除工资和联军税后入账）
- `扩建厂房` — 扩充工厂容量
- `改进生产技术到 <等级>` — 升级生产技术等级

#### 科技系统

- `提升科技` — 投入资源提升科技等级
- `提升科技到 <等级>` — 指定目标等级
- `使用科技蓝图` — 使用蓝图加速研发

#### 军事系统

可制造 17 种武器装备：

| 类型 | 装备 |
|------|------|
| 陆军（5 种） | 步兵装备、卡车、火炮、火箭炮、列车炮 |
| 空军（8 种） | 侦察机、战斗机、预警机、战术轰炸机、战略轰炸机、隐形轰炸机、大型运输机、小型运输机 |
| 弹药（4 种） | 火箭弹、防空弹药、轻型航弹、重型航弹 |

相关指令：
- `军事生产 <装备名> <数量>` — 制造武器装备
- `我的陆军装备` / `我的空军装备` / `我的弹药` — 查看库存

#### 地堡系统

修建地下设施存储装备和弹药，保护战略物资：
- `修建地堡` — 建造地下工厂 / 机库 / 弹药库
- `转移地堡物资` — 管理地下存储

#### 地区系统

- 11 种地形：浅海、中海、深海、超深海、平原、高原、浅丘、深丘、低山、中山、高山
- 6 种建筑：基础设施、公路、机场、港口、居民区、仓库
- 3 种特殊设施：生物实验室（制取生物武器）、高速离心级联（浓缩铀）、核反应堆（制取钚）
- 地区工业：炼钢厂、电解铝厂

#### 联军系统

- 3 种政体：民主制、威权制、极权制
- 4 级权限体系（1=普通成员, 4=元首），民主制/威权制下每小时动态调整
- 联军税收：0-100% 税率
- 扩军计划、生活资料分配、军队分配
- 贡献排行

#### 地图可视化

- `查看世界地图` — 生成 PNG 世界地图，按联军颜色显示领土控制
- `查看局部地图` — 以指定区域为中心的 10 格半径地图
- 全图每 10 分钟自动刷新缓存

#### 自动化服务

| 服务 | 频率 | 功能 |
|------|------|------|
| 签到重置 | 每日 | 重置签到状态、工人招募限额、联军扩军累计 |
| 生产恢复 | 每小时 | 恢复生产次数（上限 8 次） |
| 地区刷新 | 每小时 | 刷新地区工业设施空闲状态 |
| GDP 统计 | 每日 | 生成全球 GDP、平均工资、科技排行 |
| 联军统计 | 每日 | 联军资本增量 TOP10 排行榜 |

## 地图生成

本插件使用 `node-canvas` 库在服务端渲染 PNG 地图：

- 不同地形和地貌以颜色区分
- 联军控制区域叠加半透明势力色
- 全量地图和局部地图均支持
- 全图每 10 分钟自动生成并缓存，局部地图缓存 30 分钟

## 常见问题

### 提示缺少 `database` 服务

需要安装并启用 Koishi 数据库插件（如 `koishi-plugin-database-sqlite`）。

### 提示缺少 `cron` 服务

需要安装并启用 `koishi-plugin-cron-fix`。

### 提示缺少 `amIAlt` 服务

需要安装并启用 `koishi-plugin-infra-am-i-alt`。

### 注册后无法生产

确保你的工人数量、生活资料（作为工资）和生产技术等级满足要求。使用 `我的资料` 查看当前状态。

### 地图生成失败

检查系统是否安装了 `canvas` 所需的系统依赖。Windows 用户通常无需额外配置；Linux 用户可能需要安装 `libcairo2-dev`、`libjpeg-dev`、`libpango1.0-dev` 等包。
